## 📄 Resume — project entry

**Nova — Vision Board & Coach for Aspiring Musicians** — *Solo product & build · 2026*
*React, Vite, React Native (Expo), PWA · Live: nova-7iqn.vercel.app*

- Conceived and shipped a **cross-platform** app (web + native mobile) that helps Gen-Z musicians turn inspiration into tracked goals and get a **personalized path to their first break**; repositioned from a generic tracker to a sharp niche to make the value prop urgent.
- Designed a **rules-based personalization engine** mapping **6 creator archetypes** to tailored roadmaps, growth levers, and one-tap trackable next steps — deliberately choosing a **deterministic recommender over AI** for consistency, trust, and offline use.
- Scoped the MVP with **RICE + MoSCoW** (cut accounts, community, AI); defined a single **North Star metric** with an **AARRR** supporting tree and a retention-based validation hypothesis.
- Built **end-to-end** (React + Vite PWA, **Expo/React Native** app sharing one engine, local-first persistence) and authored a **full system design** — offline-first sync, REST API, data model, scaling, and privacy trade-offs.
